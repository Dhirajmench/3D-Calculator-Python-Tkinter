# 🧮 3D Calculator — Python Tkinter

A simple and modern **3D-style Calculator GUI** built using **Python and Tkinter**.
The calculator provides basic arithmetic operations with a dark user interface, raised 3D-style buttons, and an interactive display.

## 📌 Project Overview

This project demonstrates how to build a desktop calculator application using Python's built-in **Tkinter GUI library**.

The calculator allows users to perform arithmetic operations such as addition, subtraction, multiplication, division, decimal calculations, and power operations.

## ✨ Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* 🔢 Decimal calculations
* ^ Power operation
* 🧹 Clear button
* ⬅️ Backspace button
* 🟰 Calculate result
* ❌ Quit button
* 🎨 Modern dark background
* 🧊 3D-style raised buttons
* ⚠️ Division-by-zero error handling
* 🖥️ Simple desktop GUI

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/your-username/3D-Calculator.git
```

### 2. Open the project folder

```bash
cd 3D-Calculator
```

### 3. Run the calculator

```bash
python calculator.py
```

The calculator window will open on your desktop.

## 🧮 Supported Operations

| Operation      | Example      |
| -------------- | ------------ |
| Addition       | `10 + 5`     |
| Subtraction    | `10 - 5`     |
| Multiplication | `10 * 5`     |
| Division       | `10 / 5`     |
| Power          | `2 ^ 3`      |
| Decimal        | `10.5 + 2.5` |

> Note: The `^` button internally uses Python's `**` operator for power calculations.

## 🎨 User Interface

The calculator uses a dark-themed interface with:

* Dark display
* Dark 3D-style number buttons
* Orange operation buttons
* Light-colored control buttons
* Raised borders for a 3D effect

## ⚠️ Error Handling

The application handles division by zero and displays an alert message when the user tries to divide a number by zero.

Example:

```text
Cannot divide by 0!
Enter valid values
```
